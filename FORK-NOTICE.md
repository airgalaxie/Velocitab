# Airgalaxie Fork Notice

This repository is an independent Airgalaxie development fork of Velocitab.

The original Velocitab project is available at:

https://github.com/WiIIiam278/Velocitab

Velocitab was originally developed by William278, AlexDev03, and contributors.
The original copyright, license, and attribution notices remain in place.

This fork continues to be distributed under the Apache License 2.0.

Airgalaxie-specific changes include support work for Velocity 4.1 development
builds, including an internal compatibility layer, packet, Netty, and protocol
adaptations, Gradle build tooling updates, and build metadata changes for
internal development builds.

This fork is not an official Velocitab release and is not endorsed by or
supported by the original Velocitab maintainers.

Fork-specific issues should be reported to the Airgalaxie repository. Official
Velocitab releases, documentation, and original project support remain with the
upstream Velocitab project.
